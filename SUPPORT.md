# Support & Getting Help

The Ravenhelm Linear Operating Method (RLOM) is a complete, self-contained public operating model. This guide outlines how to get help, ask questions, report defects, or engage Ravenhelm for hands-on implementation.

## Community Questions & Discussion

- **Questions & Troubleshooting:** Use the [Q&A category](https://github.com/nwalker85/rlom-method/discussions) in GitHub Discussions to ask questions about applying the Method, configuring Linear, or adapting templates.
- **Show and Tell & Implementation Experiences:** Share how your team configured its workspace, custom views, or workflows in Discussions.
- **Method Proposals:** Discuss non-doctrine enhancements and integration ideas with the community before formal submission.

## Defect & Issue Reporting

- **Factual & Mechanical Defects:** If you find broken links, markdown rendering bugs, stale references, or discrepancies with Linear's current capabilities, please open a [GitHub Issue](https://github.com/nwalker85/rlom-method/issues/new/choose) using the appropriate template.
- **Doctrine Changes:** Proposing changes to the 29 numbered principles (`P-1`..`P-29`) requires an Architecture Decision Record (ADR) per [CONTRIBUTING.md](CONTRIBUTING.md). Use the Doctrine Proposal template.

## Commercial Implementation & Advisory

RLOM is designed to be self-installable on Linear Free in one week by a single Operator. However, scaling across multiple teams, integrating complex code-host topologies, or building custom agent layers often benefits from direct engagement.

Ravenhelm offers:

- **The Ravenhelm Operating Assessment:** A five-step structured engagement (discovery interview, read-only workspace audit, gap classification, phased install plan, and ongoing coaching) detailed in [Chapter 14](docs/chapters/14-the-assessment.md).
- **Hands-on Implementation & Tuning:** Custom workspace remediation, multi-repo CI/CD evidence wiring, and executive reporting alignment.
- **Agent Layer Design:** Bespoke AI-PM workflows, MCP tool routing, and automated validation gates.

For commercial inquiries, visit [Ravenhelm](https://ravenhelm.co).

## Security Vulnerabilities

To report a security concern or sensitive issue, refer to [SECURITY.md](SECURITY.md) and report privately. Do not open public issues for security vulnerabilities.
